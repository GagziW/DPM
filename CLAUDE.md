## Commit and push

- When a change is complete and its tests pass, commit it and push it to `main`. Do not wait for the user to ask.
- Each platform directory is a separate git repo. Commit and push in the repo that holds the change.
- Do not commit or push work that is not complete or that fails its tests.

## Response style

Write all responses in ASD-STE100 Simplified Technical English: short sentences, active voice, one instruction per sentence, simple and approved words.
